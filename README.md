# Playroom 🧸

A safe learning app for two small explorers, made at home.

- **Works offline**: after the first install, every game runs with the internet switched off.
- **No ads, no purchases, no accounts, no tracking.** A Content-Security-Policy stops the app from contacting any server.
- **Grown-up gate**: hold the ⚙️ button for 3 seconds to open settings.

**Bonus words**: colours, numbers, animals and praise also appear in 🇵🇹 Portuguese (pt-PT) and 🇿🇦 Afrikaans. They're spoken when the tablet has a voice installed for that language. You can switch each language on or off in settings.

## Our characters

These are original characters, designed with the *three-read rule* (silhouette → colour → detail) and round, friendly shapes:

- **Mango** 🐱: an orange cat (Memory, Colouring)
- **Tumble** 🐢: a green turtle (Shape Sorter)
- **Bo** 🤖: a red robot (Word Builder, Maths Rocket)
- **Zuzu** 🐙: a purple octopus (Bubble Pop)

## Installing on the tablets

1. **iPad (Safari):** open the site → Share button → **Add to Home Screen**.
2. **Samsung (Chrome):** open the site → ⋮ menu → **Install app** (or **Add to Home screen**).
3. Open it once while online so it can save itself, then it works offline.

**Voices**
- iPad: Settings → Accessibility → Spoken Content → Voices → download *English (UK/South Africa)* and *Portuguese (Portugal)*.
- Samsung: Settings → General management → Text-to-speech → Google → install voice data for English, *Português (Portugal)* and *Afrikaans* (offline packs).

## Updating

Change the files, bump `VERSION` in `sw.js`, then push. The tablets update the next time the app is opened while online.

## Hosting (GitHub Pages)

The app is plain HTML/JS/CSS with no build step. In the repository go to **Settings → Pages**, set *Source: Deploy from a branch*, choose `main`, `/ (root)`, and save.
